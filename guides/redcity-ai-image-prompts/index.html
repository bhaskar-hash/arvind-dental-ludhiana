Fastest: let Antigravity do all of them

  1. Open the Dr Sahu project folder in Antigravity.
  2. Paste the task below into the agent chat.
  3. It reads AI_IMAGE_PROMPTS.md, makes every image, checks it and saves it in the right place.

One at a time

  1. Pick an image below and press Copy for Antigravity (or Copy prompt for the Gemini app).
  2. Check the result with the list below before saving.
  3. Save it at the path shown, then tick Done.

Then publish

  1. Run pnpm ai-images:optimize if any are PNG or the wrong size.
  2. Run pnpm ai-images to update the checklist.
  3. Deploy: vercel deploy --prod --yes.

Task for Antigravity (all images)

Open AI_IMAGE_PROMPTS.md in this repository and follow its "Task for the Antigravity agent" section. Generate every image that is not ticked, using its prompt exactly and its aspect ratio. Before saving each one, check it: regenerate if the teeth look wrong, if any text or watermark appears, if hands or faces are distorted, or if it looks like a real photograph of a real patient. Save each image as a JPG at its exact path and size under apps/web/public/ai/. Never generate anything on the "Never generate these with AI" list. When finished, run `pnpm ai-images:optimize`, then `pnpm ai-images`, then `pnpm --filter @redcity/web build`, and tell me which images you made and any you skipped.

Never generate these with AI

    These must always be real photos, with written consent wherever a patient appears.

    Before you save an image

    • Teeth look right: the right number, evenly shaped, natural gums.
    • No text, letters, numbers or watermarks anywhere.
    • Hands and faces look normal.
    • It reads as an illustration, not a photo of a real person or clinic.
    • The colours sit with the site: cream, blush, deep red, maroon, gold.
